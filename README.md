# Eldritch Companion: F-Droid repository

This is an F-Droid repository for the Eldritch Companion app.
It has three apps. You can install them together.

| App | Languages |
|---|---|
| Eldritch Companion EN RU BG | English, Russian and Bulgarian. You can change the language during the game. |
| Eldritch Companion RU | Russian |
| Eldritch Companion BG | Bulgarian |

## Install the app

1. Install the F-Droid app from https://f-droid.org.
2. On the phone, open this link:

   https://javormin.github.io/eldritch-fdroid/repo?fingerprint=DCDD8EDF21E2EBA174B3192B19E2A84EAAD51E8E308C25B70D789C2D7CEEF328

3. In F-Droid, click "Add".
4. Search for "Eldritch". Select an app. Click "Install".

If the link does not open F-Droid, go to "Settings" > "Repositories" in F-Droid.
Click "+". Paste the link. Click "Add".
